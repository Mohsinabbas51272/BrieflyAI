# BrieflyAI Chrome Extension (Manifest V3)

Summarize any webpage, blog post, documentation, or YouTube video in 1 click directly from your browser!

---

## 🚀 How to Install in Google Chrome (Step-by-Step)

1. Open **Google Chrome**.
2. In the URL address bar, enter:
   ```
   chrome://extensions
   ```
3. In the top-right corner, turn **ON** the switch for **"Developer mode"** (ڈویلپر موڈ آن کریں).
4. In the top-left corner, click the **"Load unpacked"** (لوڈ ان پیکڈ) button.
5. In the file picker dialog, select the following folder:
   ```
   /Users/mohsinabbas/AiSummaryHub/chrome-extension
   ```
6. Click **Select / Open**.

---

## ✨ How to Use the Extension

1. Ensure the BrieflyAI backend is running on `http://localhost:3000`.
2. Open any article (e.g. Wikipedia, Medium, TechCrunch, Hacker News) or any **YouTube Video**.
3. Click the **BrieflyAI** icon in your Chrome toolbar / extensions puzzle menu.
4. Click **"⚡ Summarize Active Tab"**.
5. The extension will automatically extract the content, invoke the AI synthesis engine, and show:
   - **Executive Overview**
   - **5 Key Takeaway Points**
   - **Reading Time & Category**
   - **1-Click Copy to Markdown**
